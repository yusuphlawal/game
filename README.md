Minimal Text Adventure (no Maven)

How to build and run (Windows PowerShell):

1) Compile:

```powershell
# from project root
javac -d out src\com\example\game\*.java
```

2) Run:

```powershell
java -cp out com.example.game.Main
```

In-game commands:
- move <direction>  (e.g. move north)
- look
- take
- status
- quit / exit

No external links or resources are required. Submit the `src` folder and this README.
